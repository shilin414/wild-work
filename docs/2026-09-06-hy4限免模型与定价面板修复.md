## 2. 问题现象

1. 客户端模型菜单显示 `Hy4 preview 限时免费`（0.00x）与 `Hy4 preview`（0.29x）两条，
   但 wild-work 的定价面板里只有 `hy4-preview-x`（0.29）一条。
2. 以 `workbuddy/hy4-preview-x` 发起请求，上游返回：
   ```
   HTTP 400  code=11102  model [hy4-preview-x] service info not found
   ```
   即 `-x` 这个 id 在 chat 接口上根本不存在。

---

## 3. 根因分析

### 3.1 限免绑在「裸 id」上，不是绑在模型能力上

本机产品配置 `~/.workbuddy/cache/acc-product-config-v3.json` 中：

- `models[]`：同一模型存在多个 id，各自带独立 `credits`
  - `hy4-preview` / `hy4-preview-dev` → `x0.00`
  - `hy4-preview-x` → `x0.29`
  - `hy3` → `x0.00`，`hy3-x` → `x0.05`
- `modelPromotions[]`：限免规则显式列举了生效的 id
  ```json
  {"id":"hy4-free-trial-202608","kind":"discount",
   "modelIds":["hy4-preview","hy4-preview-dev"],
   "discount":{"discountedCredits":"0x","displayMode":"replace","factor":0},
   "badge":{"label":"限时免费"},
   "schedule":{"validFrom":"2026-08-28T00:00:00+08:00",
               "validUntil":"2026-09-11T00:00:00+08:00"}}
  ```
  对应 `hy3-free-trial-202608`，有效期到 `2026-10-01T00:00:00+08:00`。

命名规律：混元系列**裸 id = 活动价（含限免）**，`-x` 后缀 = **标准计费档**。

### 3.2 wild-work 定价面板把限免模型过滤掉了（本次修复的 bug）

`internal/upstream/client.go` → `FetchModelPricing()` 原逻辑：

```go
rate := parseCredits(m.Credits)
if rate <= 0 && m.ID != "auto" {
    continue // hunyuan-chat 等非计费模型
}
```

`hy4-preview` 的 `credits` 是 `x0.00` → `rate = 0` → 被当作「非计费模型」直接跳过。
结果定价表里只剩 `-x` 计费档，形成「该模型不免费」的错误判断。

**判据纠正**：区分「不计费」应看 `credits` 字段是否为**空字符串**，而不是 rate 是否为 0。
本机配置中 `credits` 为空的有补全模型、本地自定义模型等（如 `hunyuan-chat`、
`codewise-*`、`custom-local:*`），才应跳过。

## 4. 变更清单

### 4.1 `~/.workbuddy/models.json` — 新增限免模型条目

在 `workbuddy/hy3-x` 之后插入（第 94 行起）：

```json
{
  "id": "workbuddy/hy4-preview",
  "name": "workbuddy/hy4-preview",
  "vendor": "Custom",
  "url": "http://127.0.0.1:15721/v1/chat/completions",
  "apiKey": "WildWorkAPI",
  "supportsToolCall": true,
  "supportsImages": false,
  "supportsReasoning": true,
  "useCustomProtocol": false,
  "maxInputTokens": 1000000,
  "maxOutputTokens": 64000
}
```

参数依据上游配置：`maxInputTokens=1000000`、`maxOutputTokens=64000`、
`onlyReasoning=true`（故 `supportsReasoning=true`）、Hy4 暂不支持多模态（故 `supportsImages=false`）。

模型总数：19 → 20。**无需重启，立即生效。**

### 4.2 `wild-work/internal/upstream/client.go` — 修复定价过滤

```go
// 判据是 credits 字段是否为空，而不是 rate 是否为 0：
//   - credits 为空  → 非计费模型（补全、本地自定义等），跳过
//   - credits="x0.00" → 限时免费模型（hy4-preview / hy3 等），必须保留
// 若按 rate<=0 过滤，限免模型会被整体丢掉，定价面板只剩带 -x 后缀的
// 计费版本（hy4-preview-x x0.29），造成"该模型不免费"的误判。
if strings.TrimSpace(m.Credits) == "" && m.ID != "auto" {
    continue
}
rate := parseCredits(m.Credits)
note := ""
for _, tag := range m.Tags {
    if strings.HasPrefix(tag, "badge:") {
        note = strings.TrimPrefix(tag, "badge:")
    }
}
if note == "" && rate == 0 && m.ID != "auto" {
    note = "限时免费"
}
```

> **注意**：`git diff internal/upstream/client.go` 会同时显示另一处 `StreamHTTP`
> （流式请求无整体超时客户端）的改动，那是本次会话**之前就存在但未提交**的工作区改动，
> 不属于本次修复，但一并编译进了新 exe。

## 7. 遗留与提醒

1. **限免有效期**
   - Hy4 preview：至 **2026-09-10 23:59**（配置 `validUntil` = 2026-09-11 00:00）
   - Hy3：至 **2026-09-30 23:59**
   过期后裸 id 恢复原价，届时用 `usage.credit` 复测确认。
2. **systray 图标告警**：启动日志有
   `systray error: unable to load icon from temp file`，部署前后均存在，
   属既有问题（`build/` 下有 `trayicon.ico` / `appicon.png`，资源未正确嵌入），
   只影响托盘图标显示，HTTP API 正常。

   `-x` 是标准计费档，且 `hy4-preview-x` 在 chat 接口直接 400 不可用。
